## 🏢 Experiência — SIMDUT (01/08/2024 – 04/11/2026)

No SIMDUT desenvolvi software de apoio a simulações e análises de engenharia de oleodutos. O trabalho foi majoritariamente **C# / WPF (.NET 8 e 9)** e **Python**, com alguns módulos em **Electron** e **React**:

- **Análise de fadiga** — aplicação desktop em WPF para apoio a análises estruturais em oleodutos, com tratamento de dados operacionais.
- **Visualização e análise de dados** — aplicações desktop com mapas, tabelas e gráficos interativos para explorar dados técnicos.
- **Análise de risco** — ferramenta de apoio a avaliações de risco, com modelagem e organização de dados.
- **Geoprocessamento** — tratamento de dados geoespaciais em ferramentas internas.
- **Visão computacional** — automação de rotulagem e treino de modelos com **YOLO** e Label Studio.
- **Ferramentas internas de produtividade** — automação de relatórios e documentos, distribuição e atualização de aplicações, e utilitários para planilhas e arquivos.
- **Site institucional** em React + TypeScript + Vite + Tailwind.

> Os repositórios do trabalho são internos, por isso não estão públicos aqui.
